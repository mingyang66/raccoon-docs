##### 一、工具PyInstaller

- 将 Python 应用程序及其所有依赖项打包成单个可执行文件，用户无需安装 Python 解释器即可运行。

- 官方文档：[https://pyinstaller.org](https://pyinstaller.org)

- 安装

```
pip install pyinstaller
```

- 更新

```
pip install --upgrade pyinstaller
```

##### 

##### 二、打包

- 打包命令：

```
pyinstaller --noconsole --onefile --add-data "ui;ui" --name "AccountBook" main.py
```

--noconsole / -w：无控制台窗口（GUI 模式）。打包后的程序运行时不会弹出黑色命令行窗口，适合桌面 GUI 应用（如本项目使用 PySide6 开发的界面）。

--onefile / -F：单文件模式。将所有依赖打包成一个 exe 文件，而不是一个目录。启动时会先解压到临时目录再运行。

--add-data "ui;ui"：添加额外数据文件。格式为 "源路径;目标路径"：第一个 ui：源码目录下的 ui/ 文件夹（源），第二个 ui：打包后运行时 ui/ 的相对路径（目标）

--name "AccountBook"：指定输出文件名。生成的 exe 文件名为 AccountBook.exe，spec 文件名为 AccountBook.spec。不指定则默认为输入脚本名 main.exe。

main.py：入口脚本。PyInstaller 的分析起点，会自动递归扫描所有 import 的依赖。

- 输出目录结构：

```
├── build/          # 临时构建文件（可删除）
├── dist/           # 最终输出
│   ├── MyApp.exe   # onefile 模式：单个 exe
│   └── MyApp/      # 目录模式：exe + 依赖文件
└── MyApp.spec      # 打包配置文件（可二次编辑）
```
