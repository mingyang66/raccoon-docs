###### 一、pom文件配置central-publishing-maven-plugin插件

```
            <plugin>
                <groupId>org.sonatype.central</groupId>
                <artifactId>central-publishing-maven-plugin</artifactId>
                <version>0.10.0</version> <!-- 请检查是否有更新版本 -->
                <extensions>true</extensions>
                <configuration>
                    <!-- 必须与 settings.xml 中的 server ID 一致 -->
                    <publishingServerId>central-portal</publishingServerId>

                    <!-- 关键配置：设置为 false，这样构建时会停下来让你去网页确认 -->
                    <!-- 设置为 true 则会自动发布（不推荐初学者使用） -->
                    <autoPublish>false</autoPublish>

                    <!-- 等待状态，uploaded 表示上传到暂存库即可，无需自动发布 -->
                    <waitUntil>uploaded</waitUntil>
                </configuration>
            </plugin>
```

###### 二、pom文件配置gpg插件

官方安装gpg使用地址：[Working with PGP Signatures - Documentation](https://central.sonatype.org/publish/requirements/gpg/)

GnuPG下载地址：[https://www.gnupg.org/](https://www.gnupg.org/)

```
            <!-- 使用GnuPG签署项目的所有附加工件 -->
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-gpg-plugin</artifactId>
                <version>3.2.8</version>
                <executions>
                    <execution>
                        <id>sign-artifacts</id>
                        <phase>verify</phase>
                        <goals>
                            <!--使用GunPG对项目工件、POM和附加工件进行签名以进行部署-->
                            <goal>sign</goal>
                        </goals>
                    </execution>
                </executions>
            </plugin>
```

###### 三、生成GPG秘钥

```
gpg --gen-key
```

查看秘钥：

```
gpg --list-keys
```

###### 四、GPG公共秘钥上传到公共服务器：

```
[ERROR] Failed to execute goal org.sonatype.central:central-publishing-maven-plugin:0.10.0:publish (injected-central-publishing) on project emily-project: Execution injected-central-publishing of goal org.sonatype.central:central-publishing-maven-plugin:0.10.0:publish failed: Deployment Deployment failed while publishing -> [Help 1]
org.apache.maven.lifecycle.LifecycleExecutionException: Failed to execute goal org.sonatype.central:central-publishing-maven-plugin:0.10.0:publish (injected-central-publishing) on project emily-project: Execution injected-central-publishing of goal org.sonatype.central:central-publishing-maven-plugin:0.10.0:publish failed: Deployment Deployment failed while publishing
```

表明：Maven Central 无法在公共密钥服务器上找到你用于签名的 GPG 公钥。这是发布到中央仓库的强制要求——所有构件的签名必须能被公开验证。

首先，你需要知道你用来签名的密钥 ID。打开命令行，执行：

```
gpg --list-secret-keys --keyid-format LONG
```

```
PS D:\workplace-java\spring-parent> gpg --list-secret-keys --keyid-format LONG
sec   rsa4096/8BD96B0EA18E5162 2024-01-01 [SC]
      8BD96B0EA18E5162B94EA7F754EC3C8FA3A5B50F
uid                 [ultimate] Your Name <your.email@example.com>
ssb   rsa4096/XXXXXXXXXXXXXXXX 2024-01-01 [E]
```

> 其中 8BD96B0EA18E5162 是你的短密钥 ID，而 8BD96B0EA18E5162B94EA7F754EC3C8FA3A5B50F 是完整指纹。Maven Central 通常使用短 ID 或完整指纹进行匹配。

将公钥上传到支持的密钥服务器，Sonatype 官方支持以下三个密钥服务器（任选其一即可）：

- keys.openpgp.org（推荐，最稳定）

- pgp.mit.edu

- keyserver.ubuntu.com

使用以下命令上传你的公钥（替换为你的实际密钥 ID）：

```
gpg --keyserver keys.openpgp.org --send-keys 8BD96B0EA18E5162
```

或者使用完整指纹：

```
gpg --keyserver keys.openpgp.org --send-keys 8BD96B0EA18E5162B94EA7F754EC3C8FA3A5B50F
```

Maven中央仓库地址：[https://central.sonatype.com/](https://central.sonatype.com/)
