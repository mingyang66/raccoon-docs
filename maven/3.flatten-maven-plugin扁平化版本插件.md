flatten-maven-plugin插件可以生成maven安装和部署的pom.xml的扁平版本，而不是原始版本。官方文档：[https://www.mojohaus.org/flatten-maven-plugin/]([Flatten Maven Plugin – Maven Flatten Plugin](https://www.mojohaus.org/flatten-maven-plugin/))

###### 一、标准配置

```
<plugin>
                <groupId>org.codehaus.mojo</groupId>
                <artifactId>flatten-maven-plugin</artifactId>
                <version>${flatten-maven-plugin.version}</version>
                <configuration>
                    <updatePomFile>true</updatePomFile>
                    <!--
                      | 模式名称 | 解析所有属性? | 保留 CI 友好属性? | 保留自定义属性? | 推荐使用场景 |
                      | `full` | ✅ 是 | ❌ 否 | ❌ 否 | 需要完全静态的 POM 文件，或解决版本号未解析的报错。 |
                      | `oss` | ✅ 是 | ✅ 是 | ❌ 否 | 发布到 Maven Central 仓库，需要兼容 CI 友好变量。 |
                      | `resolveCiFriendliesOnly` | ❌ 否 | ✅ 是 | ✅ 是 | 仅替换 CI 友好变量，保留其他所有属性原样。 |
                    -->
                    <flattenMode>oss</flattenMode>
                </configuration>
                <executions>
                    <execution>
                        <id>flatten</id>
                        <phase>process-resources</phase>
                        <goals>
                            <goal>flatten</goal>
                        </goals>
                    </execution>
                    <execution>
                        <id>flatten.clean</id>
                        <phase>clean</phase>
                        <goals>
                            <goal>clean</goal>
                        </goals>
                    </execution>
                </executions>
            </plugin>
```

###### 二、flatten插件扁平版本控制

flatten插件会生成.flattened-pom.xml文件，其中会包含通过dependencyManagement依赖管理引入包的版本控制：

| 模式名称                      | 解析所有属性? | 保留 CI 友好属性? | 保留自定义属性? | 推荐使用场景                             |
| ------------------------- | ------- | ----------- | -------- | ---------------------------------- |
| `full`                    | ✅ 是     | ❌ 否         | ❌ 否      | 需要完全静态的 POM 文件，或解决版本号未解析的报错。       |
| `oss`                     | ✅ 是     | ✅ 是         | ❌ 否      | 发布到 Maven Central 仓库，需要兼容 CI 友好变量。 |
| `resolveCiFriendliesOnly` | ❌ 否     | ✅ 是         | ✅ 是      | 仅替换 CI 友好变量，保留其他所有属性原样。            |
